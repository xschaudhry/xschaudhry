## 🛠️ What I build

| Agent | What it does for you |
|---|---|
| **Quoting agent** | Turns a customer's description of the job into a draft quote built from your labor rates and parts pricing, ready for you to approve. |
| **Lead follow-up agent** | Replies to new inquiries fast, chases unanswered quotes, and books the job. |
